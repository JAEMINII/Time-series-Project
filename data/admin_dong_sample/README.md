# 서울 행정동 100곳 잠정 표본

이 폴더는 기존 `31개 상권명 + 69개 동 이름`을 동일한 공간 단위로 잘못 비교하는 문제를 바로잡기 위한 **잠정 표본**이다. 100곳이 곧 주요/비주요 상권 100곳이라는 뜻은 아니다.

## 생성 기준

- 공간 단위: 서울시 **행정동 8자리 코드**. 이름만으로 조인하지 않는다.
- 기준 기간: 2023-01 ~ 2025-12. 공식 코드 파일의 모든 월에서 코드·자치구·동명이 동일한 동만 후보로 삼았다.
- 서울 안에서 동명이 중복되는 행정동은 bare 검색어의 대상이 불분명하므로 제외했다.
- 25개 자치구별 4개 동을 선택했다. 기존 검색 데이터 중 행정동 이름과 정확히 일치하는 21개 동을 우선 포함하고, 나머지는 고정된 SHA-256 순서로 재현 가능하게 선택했다. 따라서 **대표성이나 인기 균형은 아직 보장되지 않는다**.
- 네이버 기존 값 21개 동은 검색어와 행정동명이 정확히 일치하는 **잠정 프록시**다. 검색어의 실제 의미가 동 경계와 일치하는지 검토하기 전에는 확정 지표로 쓰지 않는다.
- 다른 79개 동은 네이버 API를 재호출하지 않았으므로 검색값이 결측이다. 다른 네 가지 자료도 아직 이 표본에 맞는 원자료가 없어 결측이다. 결측을 0으로 대체하지 않는다.
- `hotspot_group`은 모두 미배정이다. 사전 기간 방문활동 등 **결과지표와 독립적인 기준**으로 나중에 주요/비주요를 구분해야 한다.

## 파일

- `sample_100_admin_dongs.csv`: 100개 코드·이름·검색 수집 상태
- `monthly_panel_100_admin_dongs_provisional.csv`: 100개 × 36개월, 3,600행의 결측 명시 패널
- `admin_dong_100_provisional.sqlite`: 같은 내용을 담은 SQLite 데이터베이스

## 출처 및 한계

- 공식 행정동 코드: [서울시 수도권 생활이동 페이지](https://data.seoul.go.kr/dataVisual/seoul/capitalRegionLivingMigration.do)의 “전국 행정동 코드정보” 다운로드 (`../reference/seoul_admin_dong_codes_official.zip`).
- 기존 검색량: `../naver/areas_100_20261106T105913Z/monthly_search_interest_100areas.csv`.
- 서울시는 생활이동의 서울 도착지를 행정동으로 제공한다. [자료 설명](https://data.seoul.go.kr/dataVisual/seoul/capitalRegionLivingMigration.do).
- [서울시 상권분석서비스(길단위인구-행정동)](https://data.seoul.go.kr/dataList/OA-22178/S/1/datasetView.do)는 **분기** 자료다. 이를 월별 관측값처럼 복제해서 조인하면 안 된다.
- 기존 `data/hotspot_100.sqlite`의 검색 영역 100곳은 공간 단위가 섞여 있으므로 분석용으로 쓰지 않는다.

## 다음 결합 규칙

1. 생활이동/생활인구/행정동 유동인구는 먼저 공식 8자리 행정동 코드와 집계 기간을 확인한다.
2. 업소 인허가 주소는 해당 월 기준 행정동에 지오코딩한다. 법정동 이름을 행정동 이름으로 직접 조인하지 않는다.
3. 지하철 역은 행정동에 바로 대입하지 않고, 역 출구 위치나 유역권 등 명시적인 공간 규칙을 정한 뒤 보조 변수로 연결한다.
4. 표본의 주요/비주요 여부는 방문활동의 사전 기간 분포를 보고 정한다. 이 표본은 그전까지 단지 재현 가능한 100개 후보일 뿐이다.
