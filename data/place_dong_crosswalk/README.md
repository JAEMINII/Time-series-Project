# 31개 검색 장소 공간 매핑 초안

재생성: 프로젝트 루트에서 `uv pip install --target tmp/pythonlibs pyshp shapely pyproj` 후 `python build_place_dong_crosswalk.py`를 실행한다.

- 공식 장소 경계: https://data.seoul.go.kr/dataList/OA-21285/F/1/datasetView.do (2026-04-02 게시된 '서울시 주요 121장소 영역.zip')
- 행정동 경계: https://data.seoul.go.kr/opendata/seoulStay/grid_viewer.html (2025-06-30 기준; 웹페이지 내 GeoJSON)
- 행정동 코드: 서울시 수도권 생활이동 페이지의 전국 행정동 코드정보, 2025-06 파일.
- 면적비 계산: 두 경계를 EPSG:5181로 투영 후 교집합. `place_area_share`는 공식 장소 중 해당 동에 걸친 비율, `dong_area_share`는 그 동 중 공식 장소에 들어가는 비율이다.
- `selected_by_5pct_rule`은 공식 장소 면적의 5% 이상과 최대 겹침 동을 표시하는 탐색 규칙이다. **해당 동의 전체 방문량을 장소 방문량으로 간주해선 안 된다.**
- 서울시 주요 121장소 경계는 2026년 게시자료다. 2023~2025년 학습기간의 경계로 고정 사용하려면 당시에도 같은 장소 범위였는지 확인해야 한다. 실시간 API에는 과거값이 없다.
- 이름이 비슷하다는 이유로 붙인 proxy는 사람이 의미와 범위를 검토해야 한다. `exclude_shared_polygon`은 서로 독립된 학습지역으로 쓰면 안 된다.

## 계산 결과와 모델 판단

- 31개 검색 장소 가운데 21개는 공식 장소 폴리곤 후보를 찾았고, 10개는 대응 폴리곤을 정할 수 없었다. 21개 중 해방촌과 경리단길은 같은 `POI082`를 가리킨다.
- 행정동 전체 면적을 공식 장소 면적과 비교하면 익선동은 약 13.05배, 청담동 명품거리는 약 25.11배다. 방문량을 행정동 전체에서 합산하여 장소 방문량으로 쓰는 방식은 이 경우 부정확하다.
- `place_to_admin_dong_overlap.csv`는 공간 참조표이며, 월별 생활이동을 장소별로 확정 조인한 데이터가 아니다. 현재 31개 중 학습 투입 확정 상태인 행은 없다.
- 장소별 검색량과 방문활동을 모두 핵심 지표로 유지하려면, 서울시 상권분석서비스의 `상권 코드` 기준 유동인구·점포 자료를 검토하고 이 장소 경계와 겹치는 상권 코드를 매핑하는 편이 낫다. 해당 자료의 기준년분기 코드와 2024년 공간 기준 변경을 반드시 확인해야 한다.
